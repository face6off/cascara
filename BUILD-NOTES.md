# Cascara 0.6

This update adds free directional movement, a centred camera with constant orientation, paged NPC and battle dialogue, 64 service and residential interiors, 12 town errands, indoor storage PCs, and shiny visuals for every species.

Save slots keep fractional player positions. Existing saves remain supported. If an old outdoor position now falls inside a building, the game moves the player to a nearby walkable position on loading. Save parsing normalises whole-number creature fields so imported or loaded creatures use the correct model.

The Windows and Linux builds include the engine and game pack. The source package contains editable assets and project files. See README.md for controls, building services, quest rewards, build commands, and remaining development work.
